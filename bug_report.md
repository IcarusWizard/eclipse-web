    - Under official Eclipse rules (Rulebook p. 20), each Engagement Round consists of all surviving ship groups firing once in strict descending order of Initiative.

    - Because `currentTurnIndex` was monotonically incremented (e.g. from 2 to 3), the subsequent step evaluated `3 % 2 = 1`, which selected the group at index 1 (Mechanema Cruisers, Initiative 2) again immediately, completely skipping index 0 (Orion Cruisers, Initiative 4)!     - Created and exported [`getActiveCombatGroup`](file:///home/xyz/eclipse-web/src/engine/rules/combatEngine.ts#L354) in `combatEngine.ts`.
